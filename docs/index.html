Good questions

Before you ask.

Can I use it on a client website now?

Not yet. The interactive example demonstrates the planned experience; it is not a working trial. There is no confirmed launch date.

Would clients need ClickUp or a browser extension?

The planned guest experience would require neither. Your agency would handle the website-script installation and ClickUp connection.

Would clients see our internal conversations?

The planned integration would expose only replies deliberately shared with clients and supported status updates—not ordinary internal ClickUp notes.

Which websites would it support?

The initial scope is review and staging websites where your agency can install the script. Compatibility, project and usage limits would be confirmed before offering access.

Does it make the requested changes?

No. It would capture and organise feedback. Your developers would still implement the changes.

What happens after I request an invitation?

Digital Hawk will follow up about your project and whether the proposed standard workflow fits. An invitation request does not guarantee access or a release date, and no payment is taken at this stage.
